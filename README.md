# Threadline Cultural Provenance Passport

An early-stage prototype exploring a designer-controlled passport for cultural context, authorship, materials, craftsmanship and supporting evidence on a garment product page.

## Demo
The static prototype is `index.html`.

## Current scope
- Responsive passport preview
- Expand/collapse garment story
- Placeholder fields for designer-approved content
- Fictional example data, not an authenticated provenance record

## Important
This is a UX prototype, not a certification service or production multi-brand widget. No database, CMS, Shopify integration, analytics or verification workflow is connected yet.

## Publish with GitHub Pages
This repository includes a GitHub Actions workflow to deploy the static site. In GitHub, open **Settings → Pages** and ensure the build and deployment source is set to **GitHub Actions**. Then open the **Actions** tab and check the deployment run.
